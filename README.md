This repository contains the assignments and practical exercises completed as part of the Database Management training.

The assignments cover the following topics:

-> Introduction to Databases

-> Database Normalization

-> Managing Databases, Tables and Collections

-> DML Statements (INSERT, UPDATE, DELETE)

-> SQL Joins

-> Subqueries

-> Window Functions

-> Transactions and ACID Properties

-> Views

-> Stored Procedures and Stored Functions

-> Cursors

-> Triggers

The assignments include practical SQL queries and MongoDB operations based on real-world business scenarios to improve database management and data manipulation skills.
