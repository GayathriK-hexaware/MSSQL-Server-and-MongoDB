# SQL Server and MongoDB Assignment

This assignment contains three sets of database tasks based on real-time business scenarios.

## Sets Covered

- **Set 1 – Logistics Shipment Analysis:** Practised SQL joins, subqueries, and MongoDB aggregation.
- **Set 2 – Bank Loan Portfolio:** Worked with loan, customer, branch, and repayment data.
- **Set 3 – Retail Returns and Refunds:** Analysed product returns, refunds, customers, and stores.

## Technologies Used
- SQL Server
- MongoDB
- SQL and JavaScript

## Files Included
- SQL scripts
- MongoDB scripts
